## How to Capture Screenshots

1. Start the server: `npm start`
2. Open browser at `http://localhost:3000`
3. Use "Load Preset: Senior Backend Developer" to populate demo data
4. Click "Execute Hybrid ATS Audit"
5. Screenshot each section and save under this directory

## Screenshot Naming Convention
```
01-dashboard.png          - Landing / Dashboard (dark mode)
02-resume-ingestion.png   - Resume upload + preset loader cards
03-ats-analysis.png       - ATS score ring + overall verdict
04-ats-breakdown.png      - ATS dimension breakdown progress bars
```
